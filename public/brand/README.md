# Brand assets

| File | Use |
|------|-----|
| `logo.png` | Sage green illustration — cream/white page backgrounds |
| `logo-light.png` | **White** illustration, **transparent** background — footer on dark green |

Nav uses wordmark only (no illustration).

## Export tips for `logo-light.png`

- Silhouette colour: **white** (`#FFFFFF`)
- Background: **transparent** (not white, not checkerboard)
- Same dimensions as `logo.png`

Save the white version as `public/brand/logo-light.png` and refresh the site.
